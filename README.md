# Full-Stack Learning Curriculum

Optional **index only**. Every topic is its own independent GitHub repo — clone one, work in one, finish one. Nothing here is required to study a topic, and no topic repo depends on another.

Use this checklist if you want a bird’s-eye progress view. Skip it if you prefer working repo-by-repo.

## Independence rule

- Each topic repo has its own README with full context, scope, outcomes, and checklist.
- No shared code, packages, or required links between topic repos.
- Order below is a suggested path, not a prerequisite graph. Jump anywhere.

## Progress checklist

### Foundations

- [ ] [01 — DSA](https://github.com/yogthesharma/dsa-foundations) — Arrays, hashing, trees, graphs, heaps, DP, sorting, complexity
- [ ] [02 — Computer Architecture](https://github.com/yogthesharma/computer-architecture) — CPU, cache, memory hierarchy, pipelines, machine instructions
- [ ] [03 — Operating Systems](https://github.com/yogthesharma/operating-systems) — Processes, threads, scheduling, memory, file systems, locks
- [ ] [04 — Concurrency and Parallelism](https://github.com/yogthesharma/concurrency-and-parallelism) — Threads vs async, event loop, race conditions, deadlocks, actor model
- [ ] [05 — Networking](https://github.com/yogthesharma/networking) — TCP/IP, HTTP/1-2-3, DNS, TLS, WebSockets, CDN, load balancing
- [ ] [06 — Languages Deep Dive](https://github.com/yogthesharma/languages-deep-dive) — JS/TS internals, Go or Rust, Python
- [ ] [07 — Compilers and Interpreters](https://github.com/yogthesharma/compilers-and-interpreters) — Lexing, parsing, ASTs, bytecode, GC, how JS engines work
- [ ] [08 — Git and Tooling](https://github.com/yogthesharma/git-and-tooling) — Git internals, monorepos, build tools, bundlers, linters

### Data

- [ ] [09 — Databases (Relational)](https://github.com/yogthesharma/databases-relational) — SQL, joins, indexes, transactions, ACID, normalization, query plans
- [ ] [10 — Databases (NoSQL)](https://github.com/yogthesharma/databases-nosql) — MongoDB, Redis, Cassandra, Neo4j, CAP theorem
- [ ] [11 — Database Internals](https://github.com/yogthesharma/database-internals) — B-trees, LSM trees, WAL, replication, sharding, isolation levels
- [ ] [12 — Search and Indexing](https://github.com/yogthesharma/search-and-indexing) — Elasticsearch, inverted indexes, full-text search, ranking
- [ ] [13 — Data Engineering](https://github.com/yogthesharma/data-engineering) — ETL, batch vs stream, Spark, warehouses, data modeling

### Backend

- [ ] [14 — Backend APIs](https://github.com/yogthesharma/backend-apis) — REST, GraphQL, gRPC, auth (JWT, OAuth), pagination, versioning
- [ ] [15 — Caching and Queues](https://github.com/yogthesharma/caching-and-queues) — Redis patterns, Kafka, RabbitMQ, pub/sub, background jobs
- [ ] [16 — Design Patterns and Architecture](https://github.com/yogthesharma/design-patterns-and-architecture) — SOLID, clean architecture, DDD, microservices vs monolith, event-driven
- [ ] [17 — Testing](https://github.com/yogthesharma/testing) — Unit, integration, e2e, mocking, TDD, load testing

### Frontend

- [ ] [18 — Frontend Advanced](https://github.com/yogthesharma/frontend-advanced) — Browser internals, rendering, performance, state management, accessibility

### Security

- [ ] [19 — Security](https://github.com/yogthesharma/security) — OWASP top 10, XSS/CSRF/SQLi, hashing, encryption, secrets management
- [ ] [20 — Cryptography](https://github.com/yogthesharma/cryptography) — Symmetric/asymmetric, signatures, certificates, how TLS really works

### Infra

- [ ] [21 — DevOps and Cloud](https://github.com/yogthesharma/devops-and-cloud) — Docker, Kubernetes basics, CI/CD, AWS core services, Terraform
- [ ] [22 — Observability](https://github.com/yogthesharma/observability) — Logging, metrics, tracing, alerting, debugging in prod
- [ ] [23 — Performance Engineering](https://github.com/yogthesharma/performance-engineering) — Profiling, benchmarking, memory leaks, flame graphs, optimization

### Capstone

- [ ] [24 — System Design](https://github.com/yogthesharma/system-design) — Scaling, caching, queues, rate limiting, consistency, common designs
- [ ] [25 — Distributed Systems](https://github.com/yogthesharma/distributed-systems) — Consensus, leader election, eventual consistency, idempotency, failure handling
- [ ] [26 — AI and ML Basics](https://github.com/yogthesharma/ai-and-ml-basics) — LLM APIs, embeddings, vector DBs, RAG, prompt engineering
